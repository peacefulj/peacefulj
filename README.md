## 在做的项目

### [PaperMate · 开源论文搭子](https://github.com/peacefulj/papermate)

把「学术论文写作决策 + 审查知识库」包装成的独立 Web 应用。覆盖从选题到投稿返修的完整生命周期，三层风险清单里既有词面检测，也有大模型逐条判读。

`Python` · `网页版 + Windows 安装包` · 一键成稿

### [研墨 · 科研工作台](https://github.com/peacefulj/wenqu)

学术写作与研究管理的本地工作台。文献、笔记、写作串在一处，PWA 可装到桌面。

`JavaScript` · `Local-first` · `PWA` · `Zotero`
